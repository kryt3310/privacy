Политика конфиденциальности

Сакура: Красная Зона

Дата вступления в силу: 28 сентября 2026 г.

1. Общие положения

Настоящая Политика конфиденциальности описывает, какие данные собирает мобильная игра «Сакура: Красная Зона» (далее — Игра), разработанная Антоновым Дмитрием (далее — Разработчик), и как они используются.

2. Какие данные мы собираем

Игра НЕ собирает персональные данные пользователей.

Игра не запрашивает и не передаёт:

  • Имя, фамилию, email, номер телефона
  • Геолокацию
  • Контакты, фото, файлы
  • Данные других приложений

3. Локальное хранение данных

Все игровые данные (прогресс, настройки звука, количество кристаллов, купленные улучшения) хранятся локально на устройстве пользователя и не передаются на серверы.

При удалении Игры все данные удаляются вместе с ней.

4. Передача данных третьим лицам

Игра НЕ передаёт данные третьим лицам.

Игра не использует:

  • Сторонние SDK для аналитики
  • Рекламные сети
  • Системы трекинга

5. Разрешения приложения

Игра запрашивает одно системное разрешение:

  • VIBRATE — для тактильной отдачи при игровых событиях (урон, смерть, победа).

6. Дети

Игра предназначена для пользователей старше 12 лет. Разработчик не собирает данные детей.

7. Изменения в политике

Разработчик может обновлять эту Политику. Актуальная версия всегда доступна на этой странице.
